# Dogecoin Cash token website

Token-only informational website for Dogecoin Cash (DOG) on BNB Smart Chain.

## Publish

In Settings → Pages, choose Deploy from a branch, main, / (root). Save. The website uses relative asset links and requires no build tools.

Set the custom domain to dogecoincash.org only after its DNS can be configured. Keep GoDaddy email records intact. Do not add historical claims about tipping, rewards, Tipestry, or future utility.

## Files

- index.html — approved token information and exchange resources
- styles.css — responsive layout
- app.js — menu and contract-copy controls
- dogecoin-cash-logo.png — original DOG token logo
- .nojekyll — publish static files directly
